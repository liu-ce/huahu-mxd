# GM 巡逻 AI 压测用法

在项目根目录执行。

## bench_gm_patrol_ai — 单题 / 多模型压测

```bash
# 默认 5 个模型，各 20 次
go run ./cmd/bench_gm_patrol_ai

# 指定轮数
go run ./cmd/bench_gm_patrol_ai -rounds 20

# 只测一个模型
go run ./cmd/bench_gm_patrol_ai -model "[L]claude-opus-4-8"
```

常用参数：`-rounds` `-model` `-timeout` `-config`

---

## bench_gm_patrol_suite — 多题汇总压测

```bash
# 内置 3 题，每题 20 次
go run ./cmd/bench_gm_patrol_suite

# 指定轮数和模型
go run ./cmd/bench_gm_patrol_suite -rounds 20 -model "[L]claude-opus-4-8"
```

常用参数：`-rounds` `-model` `-timeout` `-config`

---

API Key 读取 `assets/config/default.json` 的 `lemon_api`，也可用环境变量 `LEMON_API_KEY`。
